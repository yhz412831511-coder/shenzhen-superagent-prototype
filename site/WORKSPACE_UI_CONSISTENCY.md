# 用户工作台界面一致性基线

更新时间：2026-09-09

本文是用户工作台后续界面调整的执行基线。设计评审和代码验收均以空间角色、组件角色和交互状态为判断依据，不能只比较单个页面截图。

## 1. 空间层级

| 空间角色   | 使用范围                               | 表面令牌      | 规则                                                             |
| ---------- | -------------------------------------- | ------------- | ---------------------------------------------------------------- |
| 全局功能栏 | 左侧导航、任务右侧工作区、设置分类导航 | `--ui-side`   | 与主内容形成明确明暗差，只承载导航、工具和工作面板               |
| 主内容区   | 首页、模块正文、任务阅读区、详情内容   | `--ui-center` | 页面阅读与操作的视觉中心                                         |
| 抬升控件   | 输入框、筛选、弹窗、需要独立识别的卡片 | `--ui-raised` | 小面积使用，不得铺成第二层大背景                                 |
| 内容级双栏 | 资料库、AI记忆的列表与详情             | `--ui-center` | 两栏属于同一内容区，使用分隔线建立关系，不重复套用全局功能栏灰色 |

禁止把“左侧出现的区域”一律染成 `--ui-side`。只有承担全局导航或工具职责的区域才是功能栏；资料、记忆等对象列表属于内容浏览器。

## 2. 内容级列表与详情

资料库和 AI 记忆统一使用以下类：

- `fw-split-layout`：双栏内容容器。
- `fw-split-list-pane`：对象列表区域。
- `fw-split-detail-pane`：对象详情区域。
- `fw-split-list-item`：可选择的列表行。
- `active` 或 `is-selected`：当前对象。

共同规则：

1. 列表与详情均使用主内容底色，不形成大面积色墙。
2. 两栏只通过一条 `--ui-border` 分隔线区分。
3. 普通行透明；悬停使用 `--ui-content-list-hover`。
4. 选中只作用于当前行，使用 `--ui-content-list-selected` 和 2px 品牌色内侧标记。
5. 列表标题、数量、状态和详情字段沿用统一正文、辅助文字与边框令牌。
6. 移动端选择对象后进入全宽详情，详情仍使用主内容底色。
7. 从一级导航进入时不默认选中第一项，详情区显示中性引导空状态。
8. 只有用户主动点击，或从任务、来源、引用记录带明确对象 ID 进入时才选中对象。

## 3. 控件状态

- 默认：不额外强调容器，文字和图标服从所在空间。
- 悬停：仅反馈当前可操作对象，不改变整块区域背景。
- 选中：品牌色用于定位，不把整张列表或整栏染成品牌色。
- 聚焦：使用统一 `focus-visible` 描边；不能依赖颜色变化替代键盘焦点。
- 禁用：保留可辨文字和结构，同时降低强调度。
- 风险、提醒、成功：继续使用业务语义色，不参与页面空间分层。

## 4. 页面映射

| 页面或区域                                       | 应采用的结构                                     |
| ------------------------------------------------ | ------------------------------------------------ |
| 新任务、专业智能体、Skills、插件与连接器、自动化 | 主内容区；对象卡片按需使用抬升控件色             |
| 资料库                                           | 内容级双栏；个人资料和知识库沿用同一列表行状态   |
| AI记忆                                           | 内容级双栏；五类筛选不改变列表与详情的空间角色   |
| 设置                                             | 分类导航使用功能栏色，设置正文使用主内容色       |
| 具体任务                                         | 左右功能栏使用功能栏色，中间阅读区使用主内容色   |
| 纸张、表格、图片和原始文件预览                   | 保留内容本身的展示规则，外围工具区服从工作台主题 |

## 5. 变更前检查

每次新增或修改页面前，先回答：

1. 这个区域是全局导航、内容、工具，还是抬升控件？
2. 是否已经存在相同角色的公共类或令牌？
3. 默认、悬停、选中、聚焦、禁用五种状态是否齐全？
4. 深浅主题是否保持相同层级关系，而不是机械使用相同亮度方向？
5. `1440×900`、`919×784`、`390×844` 是否无背景断层和横向溢出？

未经说明不得新增页面私有中性色。确需例外时，应在本文件登记用途、范围和不能复用公共规则的原因。
